# Thesis-specific APA 7 rules

- **Title page**: title, author, institution, committee members, degree, date
- **Abstract**: required (max 250 words)
- **Keywords**: 3-5 required after abstract
- **Headings**: up to 5 levels allowed
- **Table of contents**: mandatory — set `toc: true` in YAML
- **List of tables and figures**: recommended if 5+ each. Set `lof: true` en YAML para índice de figuras
- **References**: comprehensive, 20+ sources typical
- **Appendices**: if applicable
